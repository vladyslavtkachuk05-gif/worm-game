# 🪱 Worm Game

Інтерактивна гра **Worm** з красивим інтерфейсом на **CustomTkinter**.

## ✅ Вимоги проекту

- ✅ **Довільна тема**: Класична гра Worm
- ✅ **CustomTkinter**: Красивий темний UI
- ✅ **Модульний підхід**: Окремі файли для логіки, UI, моделей
- ✅ **ООП**: Класи Worm, Food, GameState, ScoreManager, GameWindow
- ✅ **GitHub репозиторій**: Контроль версій

## 🎮 Як грати?

### Керування
- **W** - вверх
- **A** - вліво
- **S** - вниз
- **D** - вправо
- **SPACE** - почати/пауза
- **R** - нова гра
- **ESC** - вихід

### Правила
1. Червячок завжди рухається в одному напрямку
2. Кожна їжа дає **10 очок**
3. Після кожної їжі червячок виростає на 1 сегмент
4. Гра закінчена при:
   - Зіткненні з собою
5. Червячок вилітає з однієї сторони і появляється з іншої

## 🚀 Встановлення та запуск

### 1. Встановити залежності
```bash
pip install -r requirements.txt
```

### 2. Запустити гру
```bash
python main.py
```
